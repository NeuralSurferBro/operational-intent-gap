# Medium Article Notes

Working title:

**The Operational Intent Gap**

Subtitle:

**Why Task Completion Is an Insufficient Objective for Agentic Banking Systems**

Core thesis:

> Banks do not trust outcomes alone. They trust the process that produced those outcomes.

Core proof from this repo:

- Shortcut agent: 100% task completion, high OIG.
- Control-aware agent: 100% task completion, low OIG.

Useful diagram:

```text
Same Workflow
     |
     +--> Shortcut Agent --------> Task Completion: 100% | OIG: 92.5%
     |
     +--> Control-Aware Agent ---> Task Completion: 100% | OIG: 1.2%
```

Potential close:

> The first generation of AI agents will be evaluated by completion rates.
> The second generation will be evaluated by intent preservation.
